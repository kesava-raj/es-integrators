# B2bizz Asset Manifest

**Status:** Asset structure prepared; original quality and dimensions preserved. No page development initiated.  

---

## 1. Directory Structure Overview

The project's static asset pipeline is organized into five strict categorical folders:

```
b2bizz-reconstruction/public/
├── images/      # High-res photography, hero showcase mockups, case study cards, author portraits
├── icons/       # Partner logo SVGs, award badges, micro-glyphs (arrow, chevron, checkmark, star)
├── textures/    # Procedural SVG noise overlay and ambient glow masks
├── videos/      # Video embeds & abstract loops (reserved)
└── fonts/       # Geist Display and Inter UI WOFF2 binaries
```
